# EmsiBuddy Social

Öffentliche Bilder und Videos für Instagram und Facebook von [EmsiBuddy](https://emsibuddy.com).
Hier liegen nur fertige Inhalte für Eltern und Kinder. Kein Code, keine internen Unterlagen.

| Ordner | Inhalt |
|---|---|
| `beitraege/<serie>/` | Karussell-Bilder (JPG, 1080×1350), in Reihenfolge 1, 2, 3 … |
| `stories/` | Story-Bilder, eins pro Serie |
| `videos/` | Hochkant: Keine Lust, Atemübung. Querformat: fünf Missionen, Launch-Video |
| `emsi/posen/` | Freigestellte Emsi-Posen |
| `emsi/phasen/` | Emsi vom Ei bis zur weisen Ameise |
| `app/` | Handy-Screens der App |
| `werkstatt/` | Baukasten für die Zeichentrick-Videos (Storyboards, Engine, Ton) |

Direkter Link zu einer Datei:
`https://raw.githubusercontent.com/Nkirukasarahr/emsibuddy-social/main/<pfad>`

Quelle der Bilder: `marketing/` im App-Repo. Dort ändern und neu bauen, nicht hier.
